# ZY 双 F9P GPS 使用手册（航向版）

适用固件板型：**ZY_F9P_303_RTKGPS**（STM32F303CBT6 + u-blox NEO-F9P）

用途：双天线 **Moving Baseline**，向飞控提供 **位置 + GPS 航向（GPS-for-Yaw）**。

---

## 1. 你需要准备什么

| 项目 | 说明 |
|------|------|
| GNSS 模块 | 2× **NEO-F9P**（建议 02B），两边型号一致 |
| F9P 固件 | 两边相同，建议 **HPG ≥ 1.32** |
| CAN 节点 | 2× 本板固件（F303CBT6） |
| 天线 | 2× 多频天线，同型号、同朝向、同高度 |
| 基线长度 | 建议 **≥ 50 cm**（越短航向噪声越大） |
| 飞控 | ArduPilot，EKF3 支持 GPS yaw |

---

## 2. 接线（最重要）

### 2.1 总体示意

```
天线A ── F9P Base ──UART1── F303「Base」──┐
              │ UART2 RTCM @460800        │ CAN
              ▼                           ├──► 飞控
天线B ── F9P Rover ──UART1── F303「Rover」─┘
```

### 2.2 必须搞对的三件事

1. **两颗 F9P 的 UART2 互相直连**（传 RTCM 基线数据）  
   - Base `UART2_TX` → Rover `UART2_RX`  
   - 共地可靠，线尽量短，远离图传 / ESC  
   - **不经过 F303，不走 CAN**

2. **每颗 F9P 的 UART1 接到自己的 F303**（UBX 导航数据）  
   - 波特率由固件自动配为 **230400**

3. **两个 F303 的 CAN 接到飞控 CAN 总线**  
   - 总线两端 120Ω  
   - 波特率全机一致（默认节点 **500 kbit/s**，可与飞控统一成 1M）

### 2.3 不要做的事

- 不要把 RTCM 改走 CAN（易堵，Fixed / 航向一起变差）  
- 不要 Base / Rover 天线接反角色后却不改参数  
- 不要两边 F9P 固件版本不一致

## 3. 刷机文件说明（两套固件）

| 角色 | 板目标 | 刷机目录 |
|------|--------|----------|
| Base / 基站天线 | `ZY_F9P_303_RTKGPS_BASE` | `build/ZY_F9P_303_RTKGPS_BASE/bin/` |
| Rover / 移动站 | `ZY_F9P_303_RTKGPS_ROVER` | `build/ZY_F9P_303_RTKGPS_ROVER/bin/` |

| 文件 | 用途 |
|------|------|
| `ZY_F9P_303_RTKGPS_*_with_bl.hex` | **BL + 应用合一**（ST-Link 一次写满，推荐） |
| `ZY_F9P_303_RTKGPS_*.bin` / `.apj` | 仅应用（已有 BL 时 CAN 升级） |

Board ID 均为 **6901**。天线 A 刷 **BASE**，天线 B 刷 **ROVER**。

## 4. 节点参数（固件已写死，无需再改 GPS_TYPE）

| 参数 | BASE 固件 | ROVER 固件 |
|------|-----------|------------|
| `GPS1_TYPE` / `GPS_TYPE` | **17**（MB Base） | **18**（MB Rover） |
| `GPS_DRV_OPTIONS` | **1**（UART2 RTCM） | **1** |
| `GPS1_RATE_MS` | **200**（5 Hz） | **200** |
| `GPS1_GNSS_MODE` | **77** | **77**（两边必须相同） |
| `GPS_AUTO_CONFIG` | **1** | **1** |
| CAN 名 / 默认 Node | `ZY_F9P_Base` / **31** | `ZY_F9P_Rover` / **30** |

### 4.1 GNSS_MODE = 77 含义

`GPS + Galileo + Beidou + GLONASS`（bit 0+2+3+6）。  
两边固件强制写成 77；勿在一边改掉。若要再开 QZSS，用 **109**（77+32）。

---

## 5. 飞控参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `GPS1_TYPE` | `22` | DroneCAN Moving Baseline **Base** |
| `GPS2_TYPE` | `23` | DroneCAN Moving Baseline **Rover** |
| `GPS_AUTO_CONFIG` | `2` | 含 DroneCAN 自动配置 |
| `GPS_DRV_OPTIONS` | bit0 = 1 | 与节点一致：UART2 传基线 |
| `GPS1_POS_X/Y/Z` | 实测 | Base 天线相位中心（机体坐标，单位 m） |
| `GPS2_POS_X/Y/Z` | 实测 | Rover 天线相位中心 |
| `EK3_SRC1_YAW` | `2` | 使用 GPS 航向 |

### 5.1 天线位置怎么填

- X：机头方向为正  
- Y：机身右侧为正  
- Z：向下为正  
- 用天线 **相位中心**，不是外壳大概位置  
- 报告基线与 `POS` 差超过约 **20%**，飞控会拒绝航向  

---

## 6. 上电后 F9P 会被自动配成什么

在 `GPS_TYPE=17/18` 且 `GPS_DRV_OPTIONS` bit0=1 时：

| 接口 | Base | Rover |
|------|------|-------|
| UART2 | 只出 RTCM @460800 | 只收 RTCM @460800 |
| UART1 | 只 UBX @230400 | UBX + RELPOSNED @230400 |
| 其它 | 关 Survey-In、5 Hz、Airborne 动模 | 同左 |

一般 **不需要** 再用 u-center 手工配 UART。  
若以前用 u-center 改过，建议升级 F9P 固件后冷启动，让本节点重新 VALSET。

## 7. 地面站怎么看是否正常

### 7.1 状态

1. Base：有 3D / DGPS / RTK 均可（作移动基站）  
2. Rover：应尽量长期 **RTK Fixed**  
3. 航向：EKF / HUD 出现稳定 GPS yaw  

### 7.2 Messages 调试关键字（本固件已开）

过滤 `F9PDBG`：

| 日志 | 含义 |
|------|------|
| `F9PDBG gps.init` | 节点 GPS 已初始化 |
| `F9PDBG status ...->RTK_FIXED` | Fix 等级变化 |
| `F9PDBG yaw ON` | 航向有效 |
| `F9PDBG RelPosH hdg=.. d_cm=..` | 航向角、基线厘米数 |
| `MB Rover cfg UART2` / `MB Base cfg UART2` | 正在自动配置 F9P |

`d_cm` 应接近你的实测天线间距（厘米）。

### 7.3 快速判断卡在哪一层

| 现象 | 多半原因 |
|------|----------|
| Rover 一直 Float / 无 Fixed | 天线干扰、UART2、F9P 固件、星座不一致 |
| Rover 已 Fixed，但无航向 | 节点 TYPE 不是 17/18，或飞控不是 22/23，或 POS 不准 |
| F9P Fixed，飞控航向乱跳/闪断 | CAN 拥堵或调试刷屏；可关 DEBUG 后重试 |
| 节点不上线 | BL/应用未刷对、CAN 波特率/终端电阻 |

## 8. 日常使用建议

1. 起飞前开阔地等 Rover **Fixed** 再依赖 GPS 航向  
2. 图传天线、视频线远离 GNSS 天线  
3. 两天线馈线尽量等长、接头拧紧  
4. 改天线位置后必须重测并更新 `GPS*_POS_*`  
5. 调通后若 CAN 负载高，在 `hwdef.dat` 关闭：  
   `UBLOX_CFG_DEBUGGING` / `UBLOX_MB_DEBUGGING` / `AP_PERIPH_GPS_DEBUG_ENABLED` 后重编  

---

## 9. 验收标准（出厂 / 装机自检）

- [ ] 两颗 F9P `MON-VER` 版本 ≥ 1.32 且一致  
- [ ] UART2 直连，上电后有 `MB ... cfg UART2`  
- [ ] Rover 开阔地 **>90% 时间 RTK Fixed**  
- [ ] `RelPosH` 的 `d_cm` 与卷尺基线误差 **&lt; 10%**  
- [ ] 转动机头，航向跟随；静止时抖动可接受（视基线长度）  
- [ ] 断电重上电，无需 u-center 手工改串口

## 10. 编译（开发者）

```bash
# Bootloader
python3 Tools/scripts/build_bootloaders.py ZY_F9P_303_RTKGPS

# 应用（会嵌入 Tools/bootloaders/ZY_F9P_303_RTKGPS_bl.bin）
./waf configure --board ZY_F9P_303_RTKGPS
./waf AP_Periph
```

产物默认在 `build/ZY_F9P_303_RTKGPS/bin/`，可再复制为：

- `ZY_F9P_303_RTKGPS.bin` / `.apj` / `.elf`  
- `ZY_F9P_303_RTKGPS_with_bl.hex`  
- `ZY_F9P_303_RTKGPS_bl.bin` / `.hex`
